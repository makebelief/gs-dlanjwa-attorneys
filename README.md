# GS Dlanjwa Attorneys — Independent Website Concept

Nine-page static site. No back-end required. Deploy the contents of this folder to the existing/created Vercel project `gs-dlanjwa-attorneys`. Pages are noindex until client approval.

Important: Stock photographs in content sections are external Pexels image URLs. Check image availability after deploying. Do not publish as an authorised firm website until client permission, biographical credentials and website content are confirmed.

Share image: `assets/gs-dlanjwa-whatsapp-preview.jpg` — 1200 × 630 (logo + attorney). Verify the public URL and WhatsApp crawler access.

The enquiry form launches a mailto email draft; the visitor must send it. WhatsApp is separate.
